# Garden Manager 🌱

A simple Python project for managing an allotment garden.

The project is based on a real allotment garden and is being developed as I learn Python. Its goal is to gradually build a system for organizing information about plants, garden beds, trees and seasonal garden tasks.

## Current features

- storing information about plants and their varieties
- organizing plants into garden beds
- storing information about trees
- tracking garden tasks

## Planned development

The project will be gradually expanded with new features as I develop my Python skills.
